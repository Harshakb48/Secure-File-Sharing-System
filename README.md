# Secure-File-Sharing-System
A secure web-based application that allows users to upload, store, and share files safely using authentication, encryption, and access control mechanisms.

## Features
- User Authentication
- Secure File Upload
- File Sharing via Secure Links
- Access Control
- File Encryption
- Download Management


## Technologies Used
- HTML
- CSS
- JavaScript
- Python Flask / Node.js / Java
- MongoDB /  MySQL
